---------------------------------------------------------
* Requirements
---------------------------------------------------------

  Unity          2022.3.22f1
  VRChat SDK     Avatars 3.10.4 or later
  lilToon        2.3.3 or later   * Required

  To open the Blender file:
    Blender 4.5 LTS or later

  * This avatar is for the PC version of VRChat only.
    It is not supported on standalone Quest / Android.


---------------------------------------------------------
* Setup
---------------------------------------------------------

  1. Create a new avatar project in
     VCC (VRChat Creator Companion).

  2. Add lilToon to the project.

  3. Drag and drop Yumeka_v1.0.unitypackage into the
     Unity Project window, then click Import.

  4. Drag Assets/Yumeka/Yumeka_v1.0.prefab
     into the Hierarchy.

  5. Upload via Build & Publish in the Builder tab
     of the VRChat SDK Control Panel.

* Specifications
---------------------------------------------------------

  Triangles             84,263
  Materials             7
  Meshes                20
  Bones                 317
  PhysBones             57 (9 colliders)
  Blendshapes           388 expressions / 48 MMD / 50 body

  Blinking              Supported

---------------------------------------------------------
* Optional Assets
---------------------------------------------------------

  - 24 additional facial expressions

    Included in
    Assets/Yumeka/Yumeka v1.0/Facial/Sub_Facial/
    They are not assigned by default.

    To use them, replace the animation on any gesture
    state in the Left Hand / Right Hand layers of the
    FX controller.

    Preview images are in Image/Expression Example/.

  - Alternate body textures

    Texture/PNG/Yumeka_body.png
    Texture/PNG/Yumeka_body_Big_1.png  (default)
    Texture/PNG/Yumeka_body_Big_2.png

    Swapping these to match the breast size setting
    gives a more natural result.
