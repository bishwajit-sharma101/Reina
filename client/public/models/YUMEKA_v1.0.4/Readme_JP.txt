---------------------------------------------------------
■ 必要環境
---------------------------------------------------------

  Unity          2022.3.22f1
  VRChat SDK     Avatars 3.10.4 以降
  lilToon        2.3.3 以降   ※必須

  Blender ファイルを開く場合:
    Blender 4.5 LTS 以降

  ※本アバターは PC 版 VRChat 専用です。
    Quest / Android 単体では使用できません。


---------------------------------------------------------
■ 導入方法
---------------------------------------------------------

  1. VCC (VRChat Creator Companion) で
     新規アバタープロジェクトを作成します。

  2. lilToon をプロジェクトに導入します。

  3. Yumeka_v1.0.unitypackage を Unity の
     Project ウィンドウにドラッグ＆ドロップし、
     Import をクリックします。

  4. Assets/Yumeka/Yumeka_v1.0.prefab を
     ヒエラルキーにドラッグします。

  5. VRChat SDK Control Panel の Builder から
     Build & Publish でアップロードします。

---------------------------------------------------------
■ 差し替え用データについて
---------------------------------------------------------

  ● 予備表情 24種

    Assets/Yumeka/Yumeka v1.0/Facial/Sub_Facial/ に
    収録しています。初期状態では未使用です。

    FX レイヤーの Left Hand / Right Hand にある
    各ジェスチャーのステートで、アニメーションを
    お好みのものに差し替えてお使いください。

    見本画像は Image/Expression Example/ にあります。

  ● ボディテクスチャ差し替え用

    Texture/PNG/Yumeka_body.png
    Texture/PNG/Yumeka_body_Big_1.png(デフォルト)
    Texture/PNG/Yumeka_body_Big_2.png

    胸サイズによって差し替えると自然になります。
